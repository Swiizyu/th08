# Contributor Code of Conduct

We do not ask much, but we do ask that you:

- Be generally respectful - bigotry toward others will not be tolerated.

- Do not release builds including the game's assets, which aids in piracy, if you fork the repo.

- Do not submit PRs created primarily using AI.

- Do not use leaked materials (e.g. illegally obtained source code) to assist in the decompilation. Referencing trial builds of the game to glean additional info is okay.
